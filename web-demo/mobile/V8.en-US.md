# Asthma Helper v8 — native visual parity

## Integration

Use the complete `aeriday-mobile-source-v8.zip`, not the v7 source or a browser-only demo. Run `bun install` and `bun run build:mobile`; load all of `dist-mobile/` in WKWebView. `aeriday-dist-mobile-v8.zip` contains that static offline bundle. Keep the existing Swift/Kiro services and response envelope. No wire schema changes: nativeBridge.ts, insights.ts, doctorSummary.ts and nativeOperations.ts have identical SHA-256 fingerprints to the starting v7 source. Kiro's independent getInsights invalid_response repair is not implemented or bypassed here.

## Explicit visual diff

- AeriDayApp mounts the same TodayBody, MedsBody, TrendsExperience, HistoryExperience and MoreBody for both data modes, rather than switching the whole tab to a different native screen.
- New previewLayouts.tsx extracts the actual browser Recent changes surface, dashboard dividers, airflow motif, selected chart surface and history headings. The browser reuses those shells with unchanged synthetic content; native fills them with Swift facts and existing operation adapters.
- Today restores Recent changes → Today/environment → Medications today → Health trends (two compact rows) → Action plan → Anything unusual today? → safety text → unavailable Ask AI. Findings open the retained four-layer explanation. The symptom actions open structured CRUD, not the prototype's in-memory check-in.
- Medication schedule and inventory use the preview Panel/Row styling, with actual use kept separate. No taken checkmarks, stock percentage, low-stock thresholds, days left or adherence are invented.
- Trends restores the preview's inline selected-metric chart and grouped rows. It reads the chosen metric and 7/30/90 series through Swift, preserving supplied dates, null gaps, source ambiguity, references and review-band suppression. Full reference review controls remain in details and More.
- History uses preview section headings around real structured records and legacy notes. More retains doctor summary, sources/reference/analysis controls, reminders, privacy and existing native operations in preview surfaces.
- No global styles, design tokens, navigation, mobile fonts, permissions, clinician text or native contracts were changed. `mobile/V8.diff.patch` is the full v7-to-v8 presentation/test/architecture diff (new guides excluded from their own patch).

## Honest unavailable content

The current snapshot contract supplies no environment or clinician-authored plan. AQI/pollen/weather therefore retain the designed positions but show dashes and unavailable labels, including in DEMO native mode. Action plan opens a clear “not supplied” explanation, never the browser's hardcoded clinical plan. Ask AI remains unavailable. No browser scenario values are substituted for missing real samples. Swift is the only supplier of personal analysis; no frontend clinical conclusion or reference algorithm was added. Native synthetic verification injects an explicitly isDemo=true bridge fixture; it is not embedded as a production fallback.

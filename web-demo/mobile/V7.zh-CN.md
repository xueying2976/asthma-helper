## 更多 → Prepare for a doctor visit

选择 7 天（默认）、30 天或最多 90 个日历日的自定义首尾包含区间。默认截至昨天，不含今天。自定义模式勾选今天（部分数据）时，结束日期设为今天；关闭时设为昨天。包含部分今天的整个区间也不得超过 90 天。实际区间与时区始终由 Swift 返回。

笔记默认不选，只发送用户选中的 ID。问题可添加、编辑、删除；空白问题不发送，非空文字不改写。任何选项变更都会作废预览与 token；快照或洞察重新读取后变化也作废。原生读取失败绝不替换为示例报告；无原生桥的浏览器保留原有合成工作台，不假装生成原生报告或 PDF。

## 精确原生边界 — 不替换 v6

保留 v1 消息封装与请求 ID，在 `src/lib/aeriday/nativeBridge.ts` 的白名单、参数和返回类型中增加：

```ts
getDoctorSummary({
  range: { kind: 'last7' | 'last30' | 'custom', start?: ISO, end?: ISO, includeToday?: boolean },
  selectedNoteIds?: string[], patientQuestions?: string[]
}) -> { summary: DoctorVisitSummary, token: string }
exportDoctorSummary({ token: string, format: 'pdf' }) -> { ok: true, format: 'pdf' }
```

自定义请求 `start/end` 是**首尾包含的本地日历日零点转 ISO 字符串**，不是仅日期字符串；请求 `end` 不等于返回 `endExclusive`。这是本次首尾包含日期界面的传输解释。Swift 应在报告时区中将这些时刻解释为包含日期；本地需验证设备与报告时区一致。请求键为 **`selectedNoteIds`**，不是 `selectedNoteIDs`；报告键为 **`metricID`**，不是 `metricId`。两个新操作允许 60 秒，包含原生分享界面；超时不能证明已打开的分享界面是否完成。

`src/lib/aeriday/doctorSummary.ts` 是独立的精确报告校验边界，不更换 v6 洞察类型。报告 state/regimen/purpose/metricID 为字符串，不限制为 v6 枚举。所有计数字段是有限数值，不强制整数；`schemaVersion` 是数字，不只允许 1。必需数组即使为空也必须存在。Swift 可选键允许**省略或 null**，不补造数值。

| 报告组 | 精确字段 |
|---|---|
| 顶部 | `schemaVersion, generatedAt, timeZone, isDemo, recordRevision` |
| range | `start, endExclusive, completedDays, includesPartialToday, timeZoneIdentifier, firstInclusiveDay, lastInclusiveDay` |
| reportingCoverage | `expectedDays, knownSymptomDays, missingWearableDays` |
| symptoms[] | `field, knownDays, positiveDays, unansweredDays` |
| medicationLogs[] | `label, medicationName?, regimen, purpose, eventCount, loggedDays, totalAmount?, unit?` |
| peakFlow | `validReadingCount, minValue?, maxValue?, unit:'L/min', percentOfConfirmedBestRange?`（数值数组） |
| wearableContext[] | `metricID, unit, usableDays, missingDays, sources:string[], observedMin?, observedMax?, incompatibleSources` |
| personalChanges[] | `metricID, state, referenceStart?, referenceEnd?, referenceValidDays, recentValidDays, observedDifference?, unit, ruleVersion` |
| 其他 | `personalChangesOmittedReason?, selectedNotes:[{id,date,text}], patientQuestions:string[], limitations:string[]` |

日期使用带偏移量 ISO 字符串；表中 `?` 也允许 null。报告笔记字段为 `text`，快照为 `note`；报告内不进行字段重映射。返回不符合协议或区间时区无法显示时，提示读取失败，不猜测。不存在降级到不完整 v5 DTO 的逻辑。

## 预览与分享

顺序为顶部/范围/时区/生成时间/示例标记、覆盖率、症状、用药记录、峰流速、可穿戴背景、个人变化、选定笔记、问题、限制。保留原生名称、量、单位、状态、省略原因和文字。缺失显示 Not supplied，不变成零。显示分母、未回答天数、缺失天数、来源不兼容和个人参考日期。百分比仅展示原生确认最佳值数组；前端不计算百分比、分区、临床分数、诊断或剂量建议。日期用返回区间时区，精确 ISO 区间可展开查看。

收到 `report_stale` 时丢弃旧 token/预览，显示 **Records changed — regenerate**，按当前选项重新读取；失败可 Retry preview。错误码含 `cancel` 时保留预览并显示取消；其他错误不宣称导出成功。原生成功只确认**分享请求**完成，不确认 PDF 已保存或送达。Swift 负责 token、记录修订校验、PDF、分享界面和全部个人分析。

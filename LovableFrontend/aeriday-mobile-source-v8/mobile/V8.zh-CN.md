# AeriDay v8 — 原生界面视觉一致性

## 本机集成

请使用完整 aeriday-mobile-source-v8.zip，而非 v7 源码或仅浏览器演示。执行 bun install 与 bun run build:mobile，将整个 dist-mobile/ 加载到 WKWebView。aeriday-dist-mobile-v8.zip 为离线静态包，包含本地字体与 OFL 许可。保留现有 Swift/Kiro 服务与 v1 响应信封；nativeBridge.ts、insights.ts、doctorSummary.ts、nativeOperations.ts 与起始 v7 的 SHA-256 完全相同。未修改协议，未处理或绕过 Kiro 独立修复的 getInsights invalid_response。

## 明确差异

- AeriDayApp 在两种模式都挂载 TodayBody、MedsBody、TrendsExperience、HistoryExperience、MoreBody，不再在标签层切换到简化原生页面。
- 新 previewLayouts.tsx 提取浏览器实际的 Recent changes 容器、仪表分隔、气流图案、选中指标图表容器和记录标题。浏览器保留原演示内容，原生以 Swift 数据及现有操作适配。
- Today 恢复 Recent changes、Today/环境、今日药物、Health trends 两行、Action plan、Anything unusual today?、安全句与不可用 Ask AI 的顺序。发现项仍打开四层解释；症状按钮打开真实结构化编辑器，不使用浏览器内存打卡。
- 药物计划与库存使用原预览 Panel/Row，实际用药独立。不会虚构已服药标记、库存百分比、低库存阈值、剩余天数或依从性。
- Trends 恢复内嵌选中指标图表及分组行；选中指标与 7/30/90 天序列来自 Swift，保留原日期、空缺、来源歧义、参考与待审核区间隐藏。详细参考重建仍在详情及 More 中。
- History 以预览标题展示真实结构化记录和原自由文本。More 保留医生报告、来源/参考/分析设置、提醒、隐私及原生操作。
- 未修改全局样式、颜色、导航、本地字体、权限、医生文本或协议。mobile/V8.diff.patch 为 v7 至 v8 的完整界面/测试/架构差异，不包含指南自身。

## 诚实空态

当前 snapshot 不提供环境或医生行动计划，AQI/花粉/天气保留原位置但显示横线与不可用，原生 DEMO 亦如此。Action plan 仅说明未提供，不展示浏览器硬编码医疗计划；Ask AI 不可用。不以浏览器示例补齐真实缺失数据，不在前端计算临床结论或参考。测试注入明确 isDemo=true 的合成桥接，并非生产回退。

## 已验证

31 项单元测试通过；离线移动构建成功。check_v6.py、check_sources.py、check_review.py、check_doctor.py 在 390×844 标准浅色及 320×844 大字深色通过，来源检查的 390 也使用深色。仅为新增内嵌图表限定测试选择器，并纠正旧测试的部分保存提示文字。

check_v8.py 检查五个标签、≥44×44 CSS px 交互框、页面宽度、Today 构图、不可用计划、真实空 snapshot 不出现示例数值。已逐一查看标签、Today 下部、空态/错误/详情截图。合成检查验证真实操作路径：结构化增删改、提醒读回、部分提交、来源选择、确认重建参考，以及报告预览、过期、取消、错误。浏览器工作台仍显示原合成布局与标题。未发布、未启用 Cloud/账户/分析追踪/联网存储。

运行 bun test src/lib/aeriday/*.test.mjs mobile/*.test.mjs；在 localhost:8090 提供 dist-mobile，再逐一运行 mobile/tests/check_*.py 五个脚本。浏览器工作台检查另需 localhost:8080。
